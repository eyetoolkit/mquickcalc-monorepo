Quick reference

100 bits = $1  ·  1,000 bits = $10  ·  5,000 bits = $50  ·  10,000 bits = $100. That is the value paid out to the streamer. Buying bits costs the viewer more than that in most regions — small web packs run around $1.40 per 100 bits, while bulk packs and bonus-bit promos come closer to 1:1 — so the viewer cost and the bit value are not the same number.

How Twitch bits work

Bits are a donation currency on Twitch. A viewer uses bits to "Cheer" in chat (spending recent donations buys cheer emotes and highlights). The streamer then receives a cash payout for the cheered bits.

At the standard rate, 100 bits = $1.00, meaning the dollar value is bits / 100. Some countries and bulk packages shift the exact price a viewer pays, while the payout streamers receive is generally tied to that $0.01-per-bit value before platform deductions.

Frequently asked questions

How much is 1000 Twitch bits worth?

$10.00. That's the standard conversion: 1,000 bits ÷ 100.

Do streamers get the full value of the bits?

Usually very close to it at the $0.01-per-bit rate. Twitch's fees, currency conversion and regional rules can reduce the final amount in some cases, so treat streamer payouts as approximate.
