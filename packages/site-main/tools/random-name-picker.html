Random Name Picker

A fair random draw from any list of names. No wheel to spin, no app to install — type the names, pick how many to draw, and let chance decide.

Winners

How this name picker works

Each draw reads a secure random number from your browser via crypto.getRandomValues and picks one name uniformly from the options still in the pool. If "remove picked" is on, winners are taken out so nobody appears twice; if it is off, every draw is independent and the same name can come up again.

What to use it for

Pick who takes out the trash, split a gift-buying group, choose a presentation speaker, draw the first prize, or settle a "we can't decide" between two options. It is the same result as folding the names into slips and shaking a hat.
