How percentage works

A percentage is a fraction of 100. "25%" means "25 out of every 100" or mathematically 0.25. All four modes above are algebraically equivalent — we just rearrange which variable you want to solve for.

Frequently asked questions

Can I use this for percentage increase or decrease?

Yes — the fourth mode (% change from X to Y) handles this directly. A positive number is an increase, negative is a decrease.

Why does the third mode divide by zero?

If you enter 0 as the percentage, the original number is undefined (any number is 0% of itself). We show 0 in that case as a safe fallback.
